How it works

Evaluates all outlier filter models on your raw Scaphandre power samples and recommends the one that produces the most consistent energy measurements.

CV scoring — requires ≥ 3 separate benchmark sessions of the same containers. Each session = one make run invocation.
Injection scoring — works with a single session; injects synthetic spikes and measures recovery.
